# CampusHub

CampusHub is a simple student productivity web application built with React. It helps students manage college tasks, save useful learning resources, and organize their weekly timetable in one place.

## Features

- Dashboard with task statistics
- Add and delete tasks
- Mark tasks as completed
- Filter tasks by All, Pending, and Completed
- Add due dates to tasks
- Save learning resources with URLs
- Search saved resources
- Add and manage weekly classes
- Data persistence using localStorage
- Responsive design for desktop and mobile
- Single Page Application navigation

## Run Locally

Clone the repository:

git clone https://github.com/thiyaneshsuccess-svg/Campushub.git

Move into the project:

cd Campushub

Install dependencies:

npm install

Start the development server:

npm run dev

## Purpose

This project was created to demonstrate practical understanding of fundamental web development and React concepts through a functional student-focused application.
